## About The Project

Duck Duck Run is a third person shooter game that's written with pygame. Enemy ducks spawn at random intervals and must be shot down by the protagonist duck while avoiding obstacles in the map. 

This game was made for the ADAHack hackathon and won First Prize Overall as well as The Hoppers Challenge.
